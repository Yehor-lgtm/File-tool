Simple File Tool in Python
===============
How to use?
-----------
list         — show folder contest<br>
delete       — delete file of folder<br>
delete_file  — delete file<br>
delete_path  — delete folder<br>
info         — show file info<br>
help         — show help menu<br>
*void        — Mandatory postscript(if don't use a file) example: help void<br>

Use(linux & Mac): python3 file_tool.py (command) (file of folder)<br>
  example: `python3 file_tool.py info text.txt`<br>
Use(windows): python file_tool.py (command) (file or folder)<br>
example: `python file_tool.py info text.txt`<br>
